### Project Overview
The **Digital Detective** assignment is an independent project where I explored how my computer works behind the scenes. Across 9 missions, I practiced working in the Terminal, looked into operating system processes and file permissions, ran Python programs, solved number system conversions by hand and in code, used Git and GitHub for version control and Pull Requests, and explored computer networking concepts.

> **Note on Workflow**: Each mission was completed, documented in its own folder README, and committed separately to Git before moving to the next mission.

---

### Topics Explored
1. **Repository Setup**: Checking Python 3 and Git, making project folders, and publishing to GitHub.
2. **Computer Fundamentals & IPOS**: Understanding Input, Processing, Output, and Storage, and classifying hardware vs. software.
3. **Terminal Operations**: Learning essential terminal commands (`pwd`, `ls`, `cd`, `mkdir`, `cp`, `mv`, `cat`), flags, pipes (`|`), and package managers.
4. **Operating Systems**: Checking system storage, active processes and PIDs, understanding paths and permissions (`rwx`), and OS responsibilities.
5. **How Programs Run**: Running a Python script and comparing compilers vs. interpreters.
6. **Numbers and Data**: Converting between decimal, binary, and hexadecimal by hand and with Python, building a converter script, and character encoding (ASCII and UTF-8).
7. **Git and GitHub**: Staging, committing, creating a branch (`update-about`), opening and merging a Pull Request, and building a Git command glossary.
8. **Computer Networks**: Learning LAN, MAN, WAN, DNS, routers, protocols, packet switching, testing connectivity with `ping` and `nslookup`, and tracing what happens when opening a website.
9. **Final Report**: Reviewing all missions against the final checklist and verifying repository structure.

### How to Run the Programs

#### 1. Hello World (Mission 4)
Run this command from the main folder:
```bash
python3 mission-04-programs/hello.py
```
Output:
```
Hello from Python
```

#### 2. Number Converter (Mission 5)
Run this command from the main folder:
```bash
python3 mission-05-numbers-data/number_converter.py
```
Or switch into the folder first:
```bash
cd mission-05-numbers-data
python3 number_converter.py
```
When prompted, type any positive integer (e.g. `13`, `25`, or `255`) and press Enter to see its binary and hexadecimal representations.
