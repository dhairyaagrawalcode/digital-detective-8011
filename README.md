### Project Overview
The **Digital Detective** project is a comprehensive independent investigation into computer fundamentals, terminal operations, operating systems, processes, program execution, number systems, text encodings, version control with Git & GitHub, and computer networking. 

Each mission explores a specific domain of computer systems through hands-on terminal commands, system inspections, coding exercises, and conceptual analysis.

> **Workflow Rule**: Each mission was completed, thoroughly documented in its dedicated mission folder README using the mandatory 8-section template, and committed individually with clear, meaningful commit messages before proceeding to the next mission.

---

### Topics Explored
1. **Workspace Setup & Tooling**: Verifying Python 3, Git, directory structure conventions, and repository publishing.
2. **Computer Fundamentals & IPOS**: The Input-Processing-Output-Storage cycle, hardware vs. software taxonomy, and everyday embedded systems.
3. **Terminal Operations & Command-Line Interface**: Navigation (`pwd`, `cd`), file management (`mkdir`, `touch`, `cp`, `mv`, `cat`), flags (`-lah`), Unix pipelines (`|`), and package managers (Homebrew).
4. **Operating Systems & System Management**: Kernel info, storage monitoring (`df`), active processes and PIDs (`ps`), absolute vs. relative paths, POSIX file permissions (`rwx`), and OS responsibilities.
5. **Program Execution Models**: Writing and running Python scripts (`hello.py`), and analyzing the architectural differences between compilers and interpreters.
6. **Data Representation & Character Encodings**: Step-by-step arithmetic conversions between decimal, binary, and hexadecimal, building a Python number converter CLI tool, and character encodings (ASCII vs. UTF-8).
7. **Version Control & GitHub Collaboration**: Staging, committing, branching (`update-about`), creating and merging a Pull Request (#1), and a comprehensive Git command glossary.
8. **Computer Networking**: Network topologies and scales (LAN, MAN, WAN), core networking components (DNS, routers, protocols, packet switching, client-server architecture), diagnostics (`ping`, `nslookup`), and the end-to-end lifecycle of a web request.
9. **Final Audit & System Report**: Verification against the complete 14-point submission checklist and directory structure validation.

### How to Run the Programs

#### 1. Python Hello World (Mission 4)
From the root repository directory:
```bash
python3 mission-04-programs/hello.py
```
*Expected Output*:
```
Hello from Python
```

#### 2. Interactive Number Converter (Mission 5)
From the root repository directory:
```bash
python3 mission-05-numbers-data/number_converter.py
```
Or directly from inside the mission folder:
```bash
cd mission-05-numbers-data
python3 number_converter.py
```
*Prompt*: Enter any positive decimal integer (e.g., `13`, `25`, `255`) to view its converted binary and hexadecimal representation.

## My Learning
Through the hands-on missions completed in the Digital Detective assignment:
1. **System Integration & The IPOS Cycle**: I learned how physical hardware (sensors, keyboards, CPUs, RAM, displays, storage) coordinates systematically through the operating system kernel to convert real-world user intent into digital signals and persistent data.
2. **Command-Line Dexterity**: Gained confidence navigating filesystems, managing processes, working safely with permissions (`chmod`/`ls -l`), and chaining Unix utilities using pipes (`|`) to filter and process data.
3. **Program Execution Architectures**: Discovered how compilers optimize source code ahead-of-time into standalone binary machine code, while interpreters execute instructions dynamically at runtime, and how hybrid environments like Python utilize bytecode execution.
4. **Data Representation & Bits**: Solidified the mathematical mechanics behind binary and hexadecimal conversions, understanding how every character, symbol, or emoji resolves to standardized numbers through ASCII and UTF-8.
5. **Collaborative Version Control**: Mastered the full Git development workflow—from staging and committing locally to branching (`update-about`), publishing to GitHub, and reviewing/merging Pull Requests.
6. **Network Communication**: Understood how distributed networks interconnect across LANs, MANs, and WANs, and how DNS, routers, packet switching, and the client-server protocol model bring webpages to life in milliseconds.
